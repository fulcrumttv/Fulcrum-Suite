# Contributing to Fulcrum Suite

Thanks for your interest in helping improve Fulcrum Suite.

Fulcrum Suite is currently in public beta, and feedback, bug reports and useful suggestions are welcome.

## Reporting Bugs

Please use the GitHub **Issues** section and select the appropriate issue template.

When reporting a bug, include as much relevant information as possible, especially:

- Fulcrum Suite version
- Fulcrum Plugin version
- SimHub version
- iRacing car and track
- Session type
- Overlay affected
- Steps to reproduce the problem
- Screenshots or video when possible

## Installation and Compatibility Problems

For installation, plugin loading or compatibility problems, please use the dedicated **Installation / Compatibility** issue template.

Before submitting an issue, please verify that:

- `Fulcrum.Plugin.dll` is installed in the SimHub folder
- `Fulcrum.Core.dll` is installed in the SimHub folder
- Fulcrum Suite is enabled under **Add/remove features**
- The required overlays were successfully imported into SimHub

## Feature Requests

Ideas and suggestions are welcome.

Please use the **Feature request** issue template and explain:

- What you would like to add or change
- Why it would be useful
- How you imagine the feature working
- Any relevant examples or references

## Code Contributions

Pull requests may be considered, but please open an issue first for significant changes.

This helps avoid duplicated work and makes it possible to discuss implementation before development begins.

Please keep changes focused and avoid unrelated modifications in the same pull request.

## Development Philosophy

Fulcrum Suite aims to remain:

- Useful during real racing conditions
- Easy to configure
- Visually consistent
- Lightweight
- Reliable
- Suitable for both single-class and multiclass racing

Changes should prioritize reliability and useful driver information over unnecessary complexity.
